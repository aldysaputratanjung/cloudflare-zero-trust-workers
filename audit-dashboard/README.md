# audit-dashboard

Dashboard for audit trail generated by `justifikasi-akses`.

## Config

Set the D1 database binding `AUDIT` in `wrangler.jsonc` to the same database used by `justifikasi-akses`.

## Deploy

```bash
npm install
npx wrangler deploy
```

Open the `*.workers.dev` URL. The dashboard auto-refreshes every 10 seconds.
